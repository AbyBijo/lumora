# Lumora — Vision

**The learning operating system.**

Turn documents into guided learning paths with practice and measurable mastery.

## North star

Lumora exists to help people **truly understand information** — not just
retrieve answers. It sits between raw documents and durable knowledge:

```text
Information → Understanding → Practice → Memory → Application → Mastery
```

Every feature must advance at least one step of that pipeline. If a feature
does not improve the pipeline, it is out of scope.

## What makes Lumora different

1. **Document → Curriculum (not document → chat).** The output is a guided,
   sequential path: modules → lessons → concepts → objectives → practice.
2. **Active recall by default.** Quizzes, practice sets, mastery checks, and
   flashcards are generated automatically — the user never has to ask.
3. **Spaced repetition + mastery tracking.** Retention is a core primitive.
   SM-2 schedules every review; the dashboard measures mastery per concept,
   module, and curriculum.
4. **Source-grounded trust.** Every claim is traceable to the exact passage of
   the source document. No fabricated citations, ever.

## Principles

- Users own their data and their AI provider.
- No vendor lock-in; model-agnostic gateway.
- Transparency over magic — the system explains itself.
- Calm, premium, learning-first UI. Dark mode first, whitespace intentional,
  typography carries hierarchy, colors restrained.

## Success definition

Lumora succeeds when a user can bring in raw information and leave with
**durable understanding** — measured by retention after 30 days, completion
rates, study streaks, time-to-mastery, and source trust.
