# ADR 0002 — SQLite for dev, PostgreSQL for production (same schema)

- **Status:** Accepted
- **Date:** 2026-08-01
- **Context:** The spec recommends PostgreSQL + Prisma. Local and sandbox
  development need zero-dependency setup. Prisma's schema is provider-agnostic
  for our model (no Postgres-only types used).
- **Decision:** Default `provider = "sqlite"` with `DATABASE_URL="file:./dev.db"`.
  Documented one-line switch to `postgresql` for production. All queries are
  written portably.
- **Consequences:** Fast local iteration; the same Prisma client works for
  both. Enums stored as strings (SQLite); validated in services.
