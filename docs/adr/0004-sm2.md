# ADR 0004 — SM-2 with modern modifications as the SRS algorithm

- **Status:** Accepted
- **Date:** 2026-08-01
- **Context:** The spec allows SM-2 or custom. Retention is a core primitive,
  so scheduling must be transparent, explainable, and stateful per card.
- **Decision:** Implement SM-2 (SuperMemo 2) with standard 2020s
  modifications: separate `hard` rating, minimum ease floor (1.3), first
  interval ladder (1/3 days for good; 3/7 for easy), ease deltas per rating.
  Flashcards carry their own state; quiz outcomes reuse the same transition
  machinery for concept scheduling.
- **Consequences:** Predictable, tunable behavior; cards due today surface in
  Review mode; the algorithm is fully unit-testable in `src/lib/srs.ts`.
