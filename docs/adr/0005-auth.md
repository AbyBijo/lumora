# ADR 0005 — Local demo session; NextAuth/Clerk seam

- **Status:** **Superseded** by [ADR 0008 — Real authentication](0008-auth.md)
- **Date:** 2026-08-01 (original MVP decision)
- **Context:** The MVP needed "user auth" without a password system blocking
  the demo.
- **Decision (then):** A single `Demo Learner` account auto-created on first
  sign-in, identified by an httpOnly cookie with an opaque user id.
- **Why superseded:** Lumora is now production-ready. Demo users and implicit
  sessions were removed; users register real accounts with bcrypt-hashed
  passwords and revocable server-side sessions. The seam (`src/lib/auth/`)
  survives: swapping in NextAuth/Clerk still touches one module.
