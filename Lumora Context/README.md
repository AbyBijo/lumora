## ⚡ The 6-Stage Learning Pipeline

```
  [ 1. Information ]   ── Ingest & normalize PDFs, DOCX, Markdown, Web, Audio, OCR.
         │
         ▼
  [ 2. Understanding ] ── Deconstruct with structural summaries, ELI5/Advanced explanations, and citations.
         │
         ▼
  [ 3. Practice ]      ── Active recall with automated flashcards and adaptive diagnostic quizzes.
         │
         ▼
  [ 4. Retention ]     ── Spaced repetition (SM-2) scheduling and memory hardening.
         │
         ▼
  [ 5. Application ]   ── Synthesis with Cornell notes, concept comparison matrices, and timelines.
         │
         ▼
  [ 6. Mastery ]       ── Permanent cognitive integration, effortless fluency, and export.
```

## 🛠️ Technology Stack Overview

- **Frontend:** Next.js (App Router), React 19, TypeScript, Tailwind CSS, Zustand, TanStack Query.
- **Backend:** FastAPI (Python 3.11+), Pydantic v2, PyMuPDF, Surya / Tesseract OCR, Uvicorn.
- **Data & Retrieval:** PostgreSQL + pgvector, SQLite (Local Mode), BM25s, Redis 7.x, Cloudflare R2.
- **AI Gateway:** BYOK Multi-Provider (Anthropic, OpenRouter, OpenAI, Gemini, Mistral, Groq, Ollama).
- **Authentication:** Progressive Auth (Local-First Session $\rightarrow$ Clerk / Auth.js).
